# RII Schedule Bot (Бот с расписанием РИИ)

Телеграм-бот для быстрого и удобного просмотра расписания пар Рубцовского индустриального института (РИИ АлтГТУ).

Разработчик: yearningss (Влад) (https://github.com/yearningss)

Бот в Telegram: @rubinst_bot

## Зачем это сделано?

Каждый раз заходить на сайт института с телефона, выбирать группу в выпадающем списке и зумить таблицу расписания в браузере было неудобно. 

Поэтому я написал этого бота. Он берет данные напрямую с сервера института (через `https://www.rubinst.ru/schedule.php`), сам форматирует их в удобный вид, подсказывает какая пара идет прямо сейчас и присылает уведомления на переменах.

## Что умеет бот:

* Динамический список групп - группы не захардкожены в коде, а подтягиваются с сайта РИИ. Когда добавляются новые группы или меняются семестры, бот автоматически видит изменения.
* Быстрый поиск группы текстом - можно просто написать в чат `ИВТ-61` или `руп`, и бот сразу найдет нужную группу.
* Расписание на сегодня и завтра - с автоматическим определением четности недели (I и II неделя) и переключением на понедельник на выходных.
* Расписание на всю неделю - просмотр всей сетки на 6 дней.
* Интерактивные кнопки - можно прямо под сообщением переключать дни недели (Пн, Вт, Ср, Чт, Пт, Сб) и недели (I / II).
* Статус пары в реальном времени - показывает, какая пара идет прямо сейчас по времени г. Рубцовска (UTC+7), сколько минут до конца, какая будет следующей или сколько длится текущая перемена.
* Автоматические уведомления - за 10 или 5 минут до пары, по звонку и на перемене бот может напоминать в какую аудиторию идти и какой предмет будет.
* Выбор подгруппы - если в группе есть деление на 1-ю и 2-ю подгруппы на лабораторных, можно в настройках выбрать свою, чтобы не путаться в чужих парах.
* Звонки и экзамены - вывод официального расписания звонков и сессии.

## Стек:

* Python 3.10+
* aiogram 3.x (асинхронный бот)
* aiohttp (быстрые неблокирующие запросы к сайту РИИ)
* aiosqlite (локальная база SQLite для настроек и групп пользователей)
* python-dotenv (хранение токена в .env)

## Структура проекта:

```text
rii-schedule-bot/
├── config.py           # Настройки, пути и переменные окружения
├── database.py         # Работа с базой данных пользователей (SQLite)
├── keyboards.py        # Кнопки меню и инлайн-клавиатуры
├── main.py             # Запуск бота и фонового процесса уведомлений
├── requirements.txt    # Список библиотек
├── handlers/           # Обработчики сообщений и кнопок
│   ├── __init__.py
│   ├── start.py        # /start, /help, выбор и поиск группы
│   ├── schedule.py     # Сегодня, завтра, недели, звонки, о проекте

└── services/
    ├── __init__.py
    ├── api.py          # Парсер/клиент к schedule.php, расчет времени Рубцовска

```

## Как запустить у себя:

### 1. Склонировать репозиторий:

```bash
git clone https://github.com/yearningss/rii-schedule-bot.git
cd rii-schedule-bot
```

### 2. Создать и активировать виртуальное окружение:

```bash
python -m venv venv

# Windows:
venv\Scripts\activate

# Linux / macOS:
source venv/bin/activate
```

### 3. Поставить зависимости:

```bash
pip install -r requirements.txt
```

### 4. Настроить токен:

Скопируйте `.env.example` в `.env`:

```bash
cp .env.example .env
```

Внутри `.env` укажите свой токен от BotFather:

```env
BOT_TOKEN=твой_токен_от_BotFather
DB_PATH=data/bot.db
API_BASE_URL=https://www.rubinst.ru/schedule.php
CACHE_TTL_SECONDS=300
```

### 5. Запустить бота:

```bash
python main.py
```
