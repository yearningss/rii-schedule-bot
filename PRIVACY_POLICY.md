# Политика конфиденциальности мобильного приложения «РИИ Расписание»

Дата вступления в силу: 1 сентября 2026 года (с изменениями от 9 сентября 2026 года)

Настоящая Политика конфиденциальности регулирует порядок обработки информации при использовании мобильного приложения «РИИ Расписание» (далее - Приложение), разработанного для студентов и преподавателей Рубцовского индустриального института (РИИ АлтГТУ).

### 1. Собираемая и обрабатываемая информация
Приложение не собирает, не хранит и не передает третьим лицам персональные биометрические, паспортные, контактные (номера телефонов) или платежные данные пользователей.
Для функционирования сервиса используются исключительно следующие данные:
* Выбранный номер учебной группы и номер подгруппы (сохраняются локально на устройстве и синхронизируются с сервером для доставки расписания).
* Общедоступные данные профиля Telegram (имя, username, аватар) исключительно при добровольной авторизации через официального Telegram-бота института (@rubinst_bot) для синхронизации настроек группы между ботом и приложением.
* Анонимные технические идентификаторы:
  * Client User ID: генерируемый случайным образом псевдонимный строковый идентификатор пользователя приложения. Создается локально при первом запуске и хранится в изолированном хранилище устройства. Служит исключительно для сохранения выбранной учебной группы, подгруппы и параметров уведомлений для пользователей без авторизации через Telegram (гостевой режим), предотвращения дублирования записей в базе данных и автоматического удаления устаревших гостевых данных при смене группы или входе в учетную запись.
  * Device ID: случайный технический идентификатор установки приложения на устройстве для привязки настроек и корректной работы системных виджетов рабочего стола.
  * Технические идентификаторы формируются программно на устройстве по случайному алгоритму, являются полностью анонимными и не содержат серийных номеров, IMEI, MAC-адресов или постоянных аппаратных признаков устройства.
* Технические сведения о среде выполнения: тип операционной системы (Android или iOS) и номер версии приложения, используемые исключительно для обеспечения совместимости нативных виджетов рабочего стола, доставки обновлений и форматирования расписания.
* Технические параметры сетевых запросов к открытому API института для загрузки актуального расписания занятий.

### 2. Цели использования данных
Информация используется исключительно для:
* Отображения корректного расписания занятий и расписания звонков института.
* Обеспечения работы нативных виджетов рабочего стола Android и iOS.
* Отправки локальных напоминаний о начале пар, переменах и изменениях в расписании (по выбору пользователя).
* Предотвращения накопления дублирующихся записей в базе данных и корректного обновления настроек при смене учебной группы или выходе из учетной записи.

### 3. Хранение данных и безопасность
* Все данные расписания кэшируются локально в защищенном хранилище устройства пользователя.
* Сетевые запросы осуществляются по защищенному протоколу HTTPS.
* Приложение не использует рекламные трекеры третьих лиц (такие как Google Advertising ID, IDFA или сторонние аналитические SDK).
* Пользователь может в любой момент отвязать свое устройство и удалить данные авторизации, нажав кнопку «Выйти из аккаунта» в разделе «Настройки» приложения, либо удалив приложение с устройства.

### 4. Разрешения приложения
* Доступ к сети Интернет: исключительно для загрузки актуального расписания с сайта института и синхронизации настроек.
* Уведомления: запрашиваются добровольно для напоминаний о парах и переменах.
