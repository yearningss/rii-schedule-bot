# Политика конфиденциальности мобильного приложения «РИИ Расписание»

Дата вступления в силу: 1 сентября 2026 года

Настоящая Политика конфиденциальности регулирует порядок обработки информации при использовании мобильного приложения «РИИ Расписание» (далее - Приложение), разработанного для студентов и преподавателей Рубцовского индустриального института (РИИ АлтГТУ).

### 1. Собираемая информация
Приложение не собирает, не хранит и не передает третьим лицам персональные биометрические, паспортные или платежные данные пользователей.
Для функционирования сервиса используются исключительно:
* Выбранный идентификатор учебной группы и номер подгруппы (сохраняются локально на устройстве).
* Общедоступные данные профиля Telegram (имя, username, аватар) при добровольной авторизации через Telegram-бота института (@rubinst_bot) для синхронизации настроек группы.
* Технические данные запросов к открытому API института для загрузки актуального расписания занятий.

### 2. Цели использования данных
Информация используется исключительно для:
* Отображения корректного расписания занятий и расписания звонков института.
* Работы нативных виджетов рабочего стола Android и iOS.
* Отправки уведомлений о начале пар и изменениях в расписании (по выбору пользователя).

### 3. Хранение данных и безопасность
* Все данные расписания кэшируются локально в защищенном хранилище устройства пользователя.
* Сетевые запросы осуществляются по защищенному протоколу HTTPS.
* Приложение не использует рекламные трекеры третьих лиц.

### 4. Разрешения приложения
* Доступ к сети Интернет: исключительно для загрузки актуального расписания с сайта и синхронизации настроек.
* Уведомления: запрашиваются добровольно для напоминаний о парах.
